# Licencias de recursos del firmware

`include/openjornada/assets/spanish_font.hpp` contiene un subconjunto bitmap
generado desde `DejaVuSans.ttf` con la herramienta oficial `fontconvert` de
Adafruit GFX. Incluye el intervalo U+0020..U+00FF.

El recurso se distribuye bajo la licencia de DejaVu Fonts, cuyo texto completo
está en [DejaVu-Fonts.txt](DejaVu-Fonts.txt).
